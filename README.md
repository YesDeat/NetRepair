# NetRepair
自治式网络修复工具：一键全面检查并自动修复常见断网问题，不需要你懂网络原理。Python + tkinter 实现 An autonomous network repair tool: one-click full check and **automatic fix** for common "no internet" problems — no networking knowledge needed. Built with Python + tkinter, UI similar to security suites' network-repair feature.
